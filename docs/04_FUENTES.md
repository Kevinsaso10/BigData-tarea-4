# Fuentes técnicas

Documentación consultada para preparar y verificar el laboratorio. Fecha de consulta: 19 de noviembre de 2026.

- MongoDB, Inc. (s. f.). *Install MongoDB Community on Windows using the Zip File*. MongoDB 8.0. https://www.mongodb.com/docs/v8.0/tutorial/install-mongodb-on-windows-zip/
- MongoDB, Inc. (s. f.). *Schema validation*. MongoDB 8.0. https://www.mongodb.com/docs/v8.0/core/schema-validation/
- MongoDB, Inc. (s. f.). *$lookup aggregation stage*. MongoDB 8.0. https://www.mongodb.com/docs/v8.0/reference/operator/aggregation/lookup/
- MongoDB, Inc. (s. f.). *$avg accumulator operator*. MongoDB 8.0. https://www.mongodb.com/docs/v8.0/reference/operator/aggregation/avg/
- MongoDB, Inc. (s. f.). *cursor.explain*. MongoDB 8.0. https://www.mongodb.com/docs/v8.0/reference/method/cursor.explain/

Las versiones y sus huellas oficiales se registran en config/versiones.json. El caso de uso, las identidades ficticias y los importes son de elaboración propia. Las cifras verificadas proceden de una ejecución local de MongoDB, contrastada con un control independiente.
